# direct2logbook.

A Logbook for Private, and Professional Pilots.


The website serves Bootstrap 5.3.8 from `static/theme/dist/bootstrap/`.
For a Bootstrap update, replace the CSS and JS bundle (including source maps
and the MIT license) from the pinned npm release and update the references in
the base, landing, and standalone privacy templates. The site's
`static/theme/dist/theme.css` contains the theme rules with its embedded
Bootstrap 4 section removed. The legacy theme demo bundles are separate and
are not loaded by Django pages.
